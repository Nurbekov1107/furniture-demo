# Демо-сайт мебельной мастерской (Бишкек)

Одностраничный демо-сайт для мастерской мебели на заказ: услуги, портфолио с фильтром, этапы работы, форма расчёта стоимости → WhatsApp, отзывы, FAQ, контакты.

Живая версия: https://nurbekov1107.github.io/furniture-demo/

## Персонализация через URL
`?name=Название&phone=+996700123456&addr=ул. Примерная, 1&wa=996700123456&ig=login&hours=Пн–Сб 09:00–19:00`

Все параметры необязательны. Название и номер WhatsApp применяются в заголовке, шапке, подвале и во всех ссылках wa.me.

Контент (отзывы, цены, работы) — вымышленный, для демонстрации. Фото — Unsplash.
